## Description

גלעד שהם טוען שמדידת AI בפיתוח לפי שורות קוד היא הסיבה שלא מקבלים ROI.

בפרק הזה אירחתי את גלעד שהם, VP Engineering ומייסד MCP Israel, N8N Israel ו-AI Transformation Guild, לשיחה ישירה ומעשית על מה שבאמת עוצר ארגונים מלהתקדם עם AI בפיתוח.

דיברנו על:

למה המטריקה "40% קוד נכתב ע"י AI" מסוכנת ולא מספרת כלום
ההבדל בין code generation לבין code composition - ולמה לגו עדיף על פיסול
מה עדיין מפריד מפתח סניור מ-AI ב-2026 (ורמז: זה לא אינטליגנציה)
